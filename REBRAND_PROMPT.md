# Rebranding and Redesign LLM Prompt

Use the prompt below with an advanced LLM (like Claude 3.5 Sonnet, GPT-4o, or Gemini 1.5 Pro) along with your website code or layout screenshots to rebrand and redesign the site.

***

### 📋 Copy-Pasteable Prompt

```markdown
You are an expert Frontend Developer and UI/UX Designer. 
Your task is to rebrand and redesign the provided HTML/CSS code (or layout screenshot) for a new brand called **JurisVoice**.

### CRITICAL RULE: DO NOT CHANGE THE LAYOUT STRUCTURE
- Keep the existing HTML grid systems, classes, IDs, container wrappers, and section flows EXACTLY as they are.
- Do not add or remove major container elements, as this will break Webflow animations and responsive layouts.
- Focus strictly on visual styling (colors, typography, details) and copywriting.

---

### NEW BRAND CONCEPT: JURISVOICE
JurisVoice is an AI-powered receptionist service built exclusively for **immigration and personal injury law firms**. 

- **What it does**: It answers inbound calls 24/7, performs structured client intake, books consultations, and switches seamlessly between English and Spanish.
- **Key positioning**: It is a legal-intake specialist that replaces expensive human answering services (like Ruby or Smith.ai) at a fraction of the cost. 
- **Core benefit**: "Never miss another client call." In personal injury and immigration, a missed call is a lost case worth thousands of dollars. JurisVoice captures those missed opportunities.
- **Crucial boundary**: It is intake-only. It strictly refuses to answer legal questions ("I cannot give legal advice, but I'll make sure the attorney has your details for the consultation").
- **Design Mood**: Professional, authoritative, trustworthy, and results-focused. It should look clean, modern, and high-end.

Please redesign the styling (colors, typography, details) and rewrite all the text, headings, and testimonial copy to align with this new brand. Note: Do not hardcode specific color hex values if possible; instead, define and use clean CSS custom properties (variables) for the theme colors so they can be easily customized later.

---

### INPUT FOR REDESIGN
Here is the code (or description of the page) I want you to rebrand:

[PASTE YOUR HTML/CSS OR IMAGE DESCRIPTION HERE]
```
